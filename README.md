# Ayoub Anlouf - Engineering Portfolio

[![Live Site](https://img.shields.io/badge/Live%20Site-anlouf.vercel.app-1a1a1a?style=flat-square&logo=vercel)](https://anlouf.vercel.app/)

[![GitHub](https://img.shields.io/badge/GitHub-ayoubanlouf-181717?style=flat-square&logo=github)](https://github.com/ayoubanlouf)

A personal portfolio built with a vintage editorial / newspaper aesthetic, showcasing work in **Cloud Architecture**, **DevOps & Infrastructure**, **Automated QA**, and **Open-Source Software**.

---

## Features

- **Vintage Newspaper Design**: Editorial-style typography, classic borders, and retro visual components.
- **Dynamic GitHub Showcase**: Automatically fetches public repositories via the GitHub REST API, prioritizing pinned projects.
- **Functional Contact Form**: Direct message delivery powered by Formspree.
- **Evergreen Social Cards**: Custom Open Graph and Twitter Card preview tags (`og-image.png`) optimized for LinkedIn and social sharing.
- **Zero-Dependency & Ultra-Lightweight**: Built with pure HTML5, vanilla CSS, and JavaScript with instant loading and zero build overhead.

---

## Tech Stack

- **Markup & Styling**: Semantic HTML5, Vanilla CSS3 (CSS Grid, Flexbox, custom variables)
- **Logic**: Vanilla JavaScript (Async/Await, GitHub REST API, Formspree integration)
- **Deployment**: [Vercel](https://vercel.com/)

---

## Running Locally

No package manager or build step is required:

```bash
# Clone the repository
git clone https://github.com/ayoubanlouf/PortfolioWebsite.git

# Navigate into the project directory
cd PortfolioWebsite

# Open index.html in your browser
start index.html
```
